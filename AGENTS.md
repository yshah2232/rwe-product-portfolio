- Search origin checks use parsed host boundaries in the shared searchOrigin helper, including the hosted browser preview domain; abuse blocks return explicit errors, never zero registry results, so empty state counts remain trustworthy.
- Public comparison selection lives only in React context, never URLs or browser storage; direct search to comparison replaces saved cohort routes to prevent visitor persistence. Reports are built locally as PDFs with per-page attribution and document metadata, not recipient tracking. Public activity emitters are disabled; admin security records and registry caches remain separate.
- Comparison PDFs use deterministic registry takeaways and the already loaded ACS state snapshot, not new AI inference; this keeps findings traceable and avoids extra report processing requests. Voluntary report feedback has a separate strict intake and service-role-only table read through verified AdminCEO sessions, with no report or visitor linkage; this separates explicit feedback from passive activity tracking.
- On demand comparison summaries and chat share comparison-ai, which verifies selected registry records and intersects server verified ACS cache with the state/year rows displayed on the current page; earlier assistant messages are not factual evidence. UI conversations stay in memory and reset with selection; AI Elements and AI SDK transport provide streaming, markdown and stop without visitor retention.
- Admin routes use a separate layout and memory-only opaque sessions validated by edge functions against hashed, expiring server records; username/password are encrypted runtime secrets, never browser storage. Admin tables remain service-role-only. Password replacement invalidates sessions, and server-backed login rate limits bound attempts.
